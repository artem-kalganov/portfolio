Магазин декоративных террариумов « Тайна террариума »

Год: 2026

Тип проекта: E-commerce · Интернет-магазин

Платформа: Web

Роль: UX/UI-дизайнер

О проекте: Интернет-магазин декоративных террариумов с фильтром по сложности ухода и рекомендациями по содержанию. В проекте проработаны каталог с фильтрами, поиск, избранное, корзина, оформление заказа, личный кабинет и страница о магазине. Все страницы собраны на основе единого UI Kit с компонентами, вариантами и состояниями.
